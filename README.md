# 業界勢力図

業界ごとに主要な会社を並べ、ニュースが追い風か向かい風かを地図で見せるサイトです。

## ファイル
- `index.html` … サイト本体（トップ・業界ページ・このサイトについて を1ファイルで切り替え）
- `data/industries.json` … 業界の一覧（ここに足すとメニューとトップに業界が増える）
- `data/auto.json` / `data/semi.json` / `data/shosha.json` … 業界ごとのデータ

## 業界を増やすとき
1. `data/<id>.json` を既存のファイルと同じ形で作る
2. `data/industries.json` の `industries` に `{ "id": "<id>", "name": "業界名" }` を足す

## ニュースの書き方（各業界ファイルの news）
- `companies`：影響する会社と向き（dir: 1＝追い風、-1＝向かい風）
- `title`・`summary`：自分の言葉で書く（元記事の見出しや文章をコピーしない）
- `ongoing: true`：新しいニュースではなく「続いているテーマ」
- `tags`：国やテーマなどの補足ラベル

## 公開前に確認すること
- 時価総額（`size`）の数値と基準日。未確認の会社は `null` にすると「確認中」と表示される
- 出典が記事一覧の見出しやブログになっているニュースは、元記事や公式発表に差し替える
